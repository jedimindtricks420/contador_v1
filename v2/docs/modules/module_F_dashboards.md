## F1. Главный дашборд (`/v2/dashboard`)

**Компонент:** `DashboardClient.tsx`  
**API:** `GET /api/dashboard?periodId=`

### KPI блоки

| Блок | Источник | Формула |
|------|---------|---------|
| Выручка | JournalEntry счета 9010+9020+9030 | Кт этих счетов за период |
| Расходы | JournalEntry 9410+9420+9430+9110 | Дт этих счетов за период |
| Чистая прибыль | Выручка − Расходы + Прочие доходы − Налог | |
| Деньги в банке (UZS) | Остаток 5110 | |
| Деньги в банке (USD) | Остаток 5210 | |

### Блоки дашборда

- **Налоговый календарь** — ближайшие 5 сроков уплаты налогов из TaxCalendarEvent
- **Открытые позиции риска** — OpenItem со статусом RISK
- **Чеклист периода** — импортирована ли выписка, закрыт ли месяц
- **Транзакции к классификации** — количество NEEDS_CLARIFICATION
- **Загрузка выписки** — быстрый импорт прямо с дашборда

### UI особенности

- При смене периода через select — автоматический сброс: `uploadFile`, `previewTransactions`, `soliqFile`, `soliqData`, `soliqResult`
- Ошибки загрузки → инлайн

## F2. P&L (`/v2/pnl`)

**Компонент:** `PnLClient.tsx`  
**API:** `GET /api/pnl?periodId=`

### Формула P&L

```
Выручка        = Кт(9010 + 9020 + 9030)
COGS           = Дт(9110)
Валовая прибыль = Выручка − COGS

Расходы по реализации = Дт(9410)
Управленческие расходы = Дт(9420)
Прочие расходы         = Дт(9430)

Прочие доходы  = Кт(9390 + 9540 + другие 93xx)
Налог прибыли  = Дт(9810)

Чистая прибыль = Выручка − COGS − Расходы по реализации
               − Управленческие расходы − Прочие расходы
               + Прочие доходы − Налог прибыли
```

## F3. Cashflow (`/v2/cashflow`)

**Компонент:** `CashFlowClient.tsx`  
**API:** `GET /api/cashflow?periodId=&currency=`

Движение денег по банковским счетам за период.

| Поле | Описание |
|------|---------|
| `currency` | UZS (5110) или USD (5210) |
| `incoming` | Кт по банковскому счёту |
| `outgoing` | Дт по банковскому счёту |
| `net` | incoming − outgoing |
| `opening` | Начальный остаток |
| `closing` | Конечный остаток |

## F4. Банковские счета (`/v2/accounts`)

**Компонент:** `AccountsClient.tsx`  
**API:** `GET/POST/PUT/DELETE /api/bank-accounts`

CRUD банковских счетов организации.

- Создание: название, валюта (UZS/USD), номер счёта, остаток
- Редактирование остатка: `min="0.01"` (проверка на уровне формы)
- Удаление: 409 если есть привязанные транзакции
- Ошибки: инлайн в форме и в модале удаления
