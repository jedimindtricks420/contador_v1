## 1. Описание продукта

**Contador** — облачная система автоматизированного бухгалтерского учёта для малого и среднего бизнеса Республики Узбекистан, работающая в соответствии с НСБУ №21 (Национальные стандарты бухгалтерского учёта, приказ МЭФ РУз №191, рег. №3593 от 27.12.2024, действует с 01.01.2025).

### Ключевые характеристики

- **Автоматическая классификация** банковских транзакций через AI (GPT-4o-mini) и правила
- **Документо-центричная** модель учёта: каждая хозяйственная операция — документ с шаблоном проводок
- **7-шаговый мастер** закрытия месяца (импорт → классификация → начисления → курсовые разницы → Soliq → финализация)
- **Multi-tenant**: одна БД, организационная изоляция на уровне приложения
- **Поддержка режимов налогообложения:** НДС 12%, налог с оборота 4%, общий режим

## 3. Функциональные возможности (реализованы)

### Модуль A — Импорт банковской выписки
- Парсинг 1C XML (`.xml`) и Excel (`.xlsx`)
- SHA-256 дедупликация транзакций
- Preview первых 5 строк перед импортом
- Пакетный откат по `importBatchId`
- Импорт выписок Soliq (`my.soliq.uz`)

### Модуль B — Классификация операций
- Движок правил: INN, KEYWORD, AMOUNT_RANGE, TREASURY_ACCOUNT
- AI-классификатор: GPT-4o-mini, батчи по 20, порог уверенности 70%
- Очередь уточнений (NEEDS_CLARIFICATION) с группировкой по контрагенту

### Модуль C — Реестр транзакций и документов
- Просмотр и ручная корректировка `StagedTransaction`
- Изменение типа документа, пропуск/отмена пропуска
- Фильтры: период, статус, поиск

### Модуль D — Открытые позиции
- Мониторинг авансов, подотчётных сумм, депозитов
- Автоматический статус RISK при истечении дедлайна
- Ручное закрытие и повторное открытие

### Модуль E — Закрытие месяца (7 шагов)
1. Импорт выписки
2. Классификация
3. Реестр документов
4. Начисления (ФОТ, амортизация, аренда)
5. Курсовые разницы (ЦБ РУз)
6. Сверка с Soliq
7. Финализация (налоги, блокировка периода)

### Модуль F — Дашборды и отчёты
- Главный дашборд: KPI блоки, налоговый календарь, открытые риски
- P&L (Отчёт о прибылях и убытках)
- Cashflow (Движение денежных средств)
- Управление банковскими счетами

### Модуль G — Аналитические отчёты
- ОСВ (Оборотно-сальдовая ведомость) с субконто
- Журнал проводок
- Карточка счёта
- Субконто по контрагентам
- Бухгалтерский баланс

### Модуль H — Движок проводок
- Шаблонные проводки с expression evaluator
- Атомарные транзакции (Σ Дт = Σ Кт)
- Post / Void / Repost

### Модуль I — Аутентификация
- JWT (jose, HS256), HTTP-only cookie, 7 дней
- Регистрация, логин, logout, сброс пароля
- Edge Runtime middleware

### Модуль J — Настройки
- Настройки организации (режим налогообложения, AI порог)
- CRUD правил классификации с приоритетами
- Налоговый календарь, дедлайны открытых позиций

## 4. Нефункциональные требования

| Категория | Требование |
|-----------|-----------|
| **Доступность** | 99.5% uptime в рабочее время (09:00–18:00 UZT) |
| **Производительность** | API response < 500ms для 95% запросов |
| **Безопасность** | HTTPS, HTTP-only cookies, bcrypt (rounds 10), tenant isolation |
| **Масштабируемость** | Горизонтальное масштабирование (stateless Next.js + shared DB) |
| **Совместимость** | Chrome 100+, Firefox 100+, Safari 15+, Edge 100+ |
| **Локализация** | Русский язык (UI), UZS/USD валюты |

---

## 5. Технические ограничения

- **Глобальный план счетов**: таблица `Account` без `orgId` — счета общие для всех организаций
- **Один инстанс AI**: нет per-org изоляции очередей классификации
- **SQLite не поддерживается**: требуется PostgreSQL 16+
- **Нет SSO/OAuth**: только email + password авторизация

## 6. Глоссарий

| Термин | Определение |
|--------|-----------|
| **StagedTransaction** | Импортированная банковская транзакция до её проведения |
| **Document** | Проведённый хозяйственный документ с JournalEntry |
| **JournalEntry** | Бухгалтерская проводка (Дт/Кт счёт, сумма) |
| **OpenItem** | Открытая позиция на буферном счёте (аванс, подотчёт, депозит) |
| **Period** | Учётный период (год + месяц), может быть OPEN или CLOSED |
| **PostingTemplate** | JSON-шаблон, описывающий проводки документа |
| **importBatchId** | UUID пакета импорта, объединяет транзакции для отката |
| **НСБУ** | Национальные стандарты бухгалтерского учёта РУз |
| **ОСВ** | Оборотно-сальдовая ведомость |
| **ФОТ** | Фонд оплаты труда |
| **ЦБ РУз** | Центральный банк Республики Узбекистан |
| **НДФЛ** | Налог на доходы физических лиц (12%) |
| **Soliq** | Налоговый орган РУз, портал my.soliq.uz |
| **ЭСФ** | Электронный счёт-фактура (через Soliq) |
