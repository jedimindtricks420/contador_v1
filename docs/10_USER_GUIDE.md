# 10 — Руководство пользователя

**Документ:** User Guide  
**Версия:** 2.0  
**Дата:** 2026-06-26  
**Приложение:** https://contador.uz/v2

---

## 1. Начало работы

### 1.1 Регистрация

1. Перейдите на `https://contador.uz/v2/register`
2. Заполните форму:
   - **Имя** — ваше имя
   - **Email** — рабочий адрес электронной почты
   - **Пароль** — минимум 8 символов
   - **Название организации** — наименование вашей компании
3. Нажмите «Зарегистрироваться»

После регистрации вы попадёте на главный дашборд организации.

### 1.2 Вход в систему

1. Перейдите на `https://contador.uz/v2/login`
2. Введите Email и Пароль
3. Нажмите «Войти»

### 1.3 Восстановление пароля

1. На странице входа нажмите «Забыли пароль?»
2. Введите Email вашей учётной записи
3. Проверьте почту — ссылка для сброса действует **1 час**
4. Перейдите по ссылке и установите новый пароль

## 2. Настройка организации

### 2.1 Основные настройки

Перейдите в **Настройки → Организация** (`/v2/settings`).

| Поле | Описание |
|------|---------|
| Название | Юридическое наименование |
| ИНН | 9-значный ИНН организации |
| Режим налогообложения | Налог с оборота (4%) или НДС (12%) |
| Плательщик НДС | Включить если применяете НДС-режим |
| Вид деятельности | Используется для точной AI-классификации |

### 2.2 Банковские счета

**Настройки → Банковские счета** (`/v2/accounts`)

1. Нажмите «Добавить счёт»
2. Укажите: название, валюту (UZS/USD), банк, номер счёта, начальный остаток
3. Сохраните

> **Важно:** Нельзя удалить счёт, к которому привязаны транзакции. Сначала откатите импорт.

### 2.3 Приглашение коллег

**Настройки → Участники** (`/v2/settings/members`)

1. Нажмите «Пригласить»
2. Введите Email коллеги
3. Выберите роль:
   - **Администратор** — полный доступ, управление участниками
   - **Бухгалтер** — работа с данными и отчётами

## 3. Ежемесячный рабочий процесс

### Обзор 7-шагового мастера закрытия месяца

Перейдите в **Закрытие месяца** (`/v2/closing`) и выберите нужный период.

---

### Шаг 1 — Импорт банковской выписки

1. Выберите банковский счёт из списка
2. Нажмите «Выбрать файл»:
   - **Excel** (`.xlsx`) — выписка в формате Excel
   - **1C XML** (`.xml`) — выгрузка из 1С
3. Нажмите «Предпросмотр» — увидите первые 5 строк
4. Нажмите «Импортировать» — все транзакции загрузятся в систему

> **Дедупликация:** повторная загрузка той же выписки не создаст дублей.

> **Откат:** Если загрузили не тот файл, нажмите «Откатить импорт» — все транзакции пакета будут удалены.

---

### Шаг 2 — Классификация операций

Система автоматически классифицирует транзакции:

1. **Движок правил** — мгновенно сопоставляет по ИНН, ключевым словам и сумме
2. **AI-классификатор** — для оставшихся транзакций запрашивает GPT-4o-mini

**Очередь уточнений** — транзакции, которые AI не смог классифицировать уверенно:

- Показывается рекомендация AI с процентом уверенности
- Нажмите «Это верно» → подтвердить рекомендацию
- Или выберите тип документа вручную из списка
- Чекбокс «Запомнить для контрагента» → создаёт правило, следующий раз система распознает автоматически
- «Пропустить» → оставить для ручной обработки позже

---

### Шаг 3 — Реестр документов

Просмотр всех транзакций периода. Здесь можно:

- Изменить тип документа (выберите из списка → нажмите «✓»)
- Пропустить транзакцию → «Пропустить»
- Отменить пропуск → «Снять пропуск»

---

### Шаг 4 — Начисления

Введите суммы начислений, которые **не отражены в банковской выписке**:

| Поле | Проводки |
|------|---------|
| ФОТ (фонд оплаты труда) | Д 9420 / К 6710; НДФЛ 12%: Д 6710 / К 6410; Соцналог 12%: Д 9420 / К 6520 |
| Амортизация ОС | Д 9430 / К 0200 |
| Аренда | Д 9420 / К 6010 |

Если ничего не нужно начислять — оставьте 0 и нажмите «Далее».

> «Сбросить» — удаляет все начисления шага 4 (требует подтверждения).

---

### Шаг 5 — Курсовые разницы

Для организаций с валютным счётом (USD):

1. Введите **официальный курс ЦБ РУз** на последний день периода
2. Система автоматически рассчитает курсовую разницу:
   - Положительная разница → доход (Д 5210 / К 9540)
   - Отрицательная разница → расход (Д 9620 / К 5210)
3. Нажмите «Применить»

> Текущий курс ЦБ загружается автоматически с сайта ЦБ РУз.

---

### Шаг 6 — Сверка с Soliq

1. Зайдите в my.soliq.uz → экспортируйте реестр ЭСФ за период в Excel
2. Загрузите файл в системе
3. Система сопоставит ЭСФ с транзакциями и покажет статистику (N сопоставлено / M не сопоставлено)
4. Шаг можно пропустить, если не работаете с ЭСФ

---

### Шаг 7 — Финализация

Последний шаг — закрытие периода.

**Перед закрытием система:**
- Начисляет все налоги (по режиму налогообложения)
- Проводит все документы начислений
- Блокирует период (нельзя добавить транзакции задним числом)
- Создаёт налоговый календарь на следующий месяц

Нажмите «Закрыть месяц» и подтвердите.

> **Период CLOSED нельзя открыть повторно.** Убедитесь что все данные верны.

## 4. Дашборд

**Главный дашборд** (`/v2/dashboard`) — центральная страница с ключевыми показателями.

### KPI блоки

| Показатель | Источник |
|-----------|---------|
| Выручка | Кт счетов 9010 + 9020 + 9030 |
| Расходы | Дт счетов 9410 + 9420 + 9430 + 9110 |
| Чистая прибыль | Выручка − Расходы + Прочие доходы − Налог |
| Деньги в банке (UZS) | Остаток 5110 |
| Деньги в банке (USD) | Остаток 5210 |

### Панели дашборда

- **Налоговый календарь** — ближайшие 5 сроков уплаты налогов
- **Открытые позиции риска** — авансы и подотчётные суммы с истёкшим сроком
- **Чеклист периода** — импортирована ли выписка, закрыт ли месяц
- **Транзакции к классификации** — количество NEEDS_CLARIFICATION
- **Быстрый импорт** — загрузить выписку прямо с дашборда

## 5. Отчёты

### 5.1 P&L (Отчёт о прибылях и убытках)

`/v2/pnl` — помесячный P&L за выбранный период.

Показывает: Выручку, Себестоимость, Валовую прибыль, Расходы по видам, Прочие доходы/расходы, Налог на прибыль, Чистую прибыль.

### 5.2 Cashflow (Движение денежных средств)

`/v2/cashflow` — поступления и выбытия по банковским счетам.

Выберите счёт (UZS или USD) и период. Показывает начальный/конечный остаток, суммарные поступления и выбытия.

### 5.3 ОСВ (Оборотно-сальдовая ведомость)

`/v2/reports/osv` — сальдо и обороты по всем счетам за период.

- Выберите период (с/по)
- Включите «Расширить субконто» для детализации по контрагентам
- Скачайте в Excel

### 5.4 Журнал проводок

`/v2/reports/journal` — список всех бухгалтерских проводок за период с возможностью фильтра по счёту.

### 5.5 Карточка счёта

`/v2/reports/account-card` — история движения по конкретному счёту с нарастающим сальдо.

## 6. Транзакции

`/v2/transactions` — реестр всех импортированных операций.

### Фильтры

| Фильтр | Варианты |
|--------|---------|
| Период | Выбор из списка |
| Статус | ALL / IMPORTED / AUTO_MATCHED / NEEDS_CLARIFICATION / CONFIRMED / POSTED / SKIPPED |
| Поиск | По описанию и контрагенту (с задержкой 15 мс) |

### Статусы транзакций

| Статус | Описание |
|--------|---------|
| IMPORTED | Только что загружена, не классифицирована |
| AUTO_MATCHED | Автоматически классифицирована (правилом или AI) |
| NEEDS_CLARIFICATION | AI не уверен, нужно уточнение пользователя |
| CONFIRMED | Пользователь подтвердил классификацию |
| POSTED | Документ проведён, проводки созданы |
| SKIPPED | Пропущена вручную |

## 7. Открытые позиции

`/v2/open-positions` — мониторинг буферных счетов.

### Что отслеживается

- **Авансы выданные** (4310) — деньги отправлены поставщику, товар/услуга ещё не получены
- **Авансы полученные** (6310) — деньги получены от покупателя, отгрузка ещё не сделана
- **Подотчётные суммы** (4220) — выданы деньги сотруднику в командировку
- **Займы от учредителей** (6820)
- **Депозиты** (5830)

### Статусы

| Статус | Описание |
|--------|---------|
| OPEN | Позиция открыта, срок не истёк |
| RISK | Срок закрытия истёк, требует внимания |
| CLOSED | Позиция закрыта |

### Действия

- **Закрыть** → ручное закрытие с указанием причины
- **Открыть повторно** → только для позиций, закрытых вручную

## 8. Правила классификации

`/v2/settings/rules` — настройка автоматической классификации транзакций.

### Типы правил

| Тип | Пример matchValue | Когда применяется |
|-----|-------------------|------------------|
| ИНН | `301846873` | Платёж от/поставщику с этим ИНН |
| Ключевое слово | `аренда офис` | Слово встречается в описании платежа |
| Диапазон суммы | `1000000:5000000` | Сумма в указанном диапазоне (сумы) |
| Счёт казначейства | `00304272346` | Код казначейства в описании (налоги) |

### Порядок применения

Правила применяются по очереди (сверху вниз). Первое совпадение используется.  
Порядок можно изменить перетаскиванием.

## 10. Частые вопросы (FAQ)

**Q: Как добавить транзакцию вручную (без импорта)?**  
A: Создайте документ через форму реестра. В данной версии доступен только импорт из выписки или ручное добавление через API.

**Q: Что делать если AI неправильно классифицировал платёж?**  
A: В реестре транзакций (`/v2/transactions`) выберите транзакцию, измените тип документа через select и нажмите «✓». Если это регулярный контрагент — создайте правило, чтобы AI больше не ошибался.

**Q: Можно ли открыть закрытый период?**  
A: Нет. Закрытый период заблокирован. Обратитесь к системному администратору для ручного сброса через admin-панель.

**Q: Почему сумма в P&L не совпадает с банковским остатком?**  
A: P&L считается по методу начислений (когда заработано/потрачено), а остаток в банке — по кассовому методу (когда поступило/ушло). Разница — это непроведённые авансы и отсроченные платежи.

**Q: AI работает на русском языке?**  
A: Да. Транзакции из узбекских банков обычно содержат описание на русском языке. AI-классификатор оптимизирован для работы с русскоязычными описаниями платежей и реквизитами в формате РУз.

**Q: Как поменять вид деятельности для улучшения AI-классификации?**  
A: Перейдите в Настройки → Организация (`/v2/settings`) и обновите поле «Вид деятельности». Это описание передаётся AI в системном промпте при каждой классификации.
