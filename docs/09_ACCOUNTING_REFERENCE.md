## 4. Шаблоны типовых проводок

### 4.1 Поступление оплаты от покупателя (без НДС)

```
Д 5110 «Расчётный счёт» / К 9010 «Выручка»
Сумма: amount
```

### 4.2 Поступление оплаты (с НДС 12%)

```
Д 5110 «Расчётный счёт»      / сумма с НДС
К 9030 «Выручка от услуг»    / сумма / 1.12
К 6410 «Налоги к уплате»     / сумма - сумма / 1.12
```

### 4.3 Оплата поставщику

```
Д 6010 «Кредиторская задолженность» / К 5110 «Расчётный счёт»
Сумма: amount
Субконто: контрагент (Д)
```

### 4.4 Выплата зарплаты

```
Д 6710 «Расчёты с персоналом» / К 5110 «Расчётный счёт»
Сумма: amount
```

### 4.5 Начисление ФОТ (салари-аккруал)

```
Д 9420 «Управленческие расходы» / К 6710 «Расчёты с персоналом» = salaryAmount
Д 6710 «Расчёты с персоналом» / К 6410 «Налоги к уплате» = salaryAmount × 12% (НДФЛ)
Д 9420 «Управленческие расходы» / К 6520 «Соц. налог» = salaryAmount × 12% (Соцналог)
```

### 4.6 Начисление амортизации ОС

```
Д 9430 «Прочие расходы» / К 0200 «Износ ОС»
Сумма: depreciationAmount
```

### 4.7 Начисление аренды

```
Д 9420 «Управленческие расходы» / К 6010 «Кредиторская задолженность»
Сумма: rentAmount
```

### 4.8 Уплата налога

```
Д 6410 «Налоги к уплате» / К 5110 «Расчётный счёт»
Сумма: amount
```

### 4.9 Курсовая разница (доход)

```
Д 5210 «Валютный счёт» / К 9540 «Доходы от курсовой разницы»
difference > 0 → доход
```

### 4.10 Курсовая разница (расход)

```
Д 9620 «Расходы от курсовой разницы» / К 5210 «Валютный счёт»
difference < 0 → расход
```

### 4.11 Налог с оборота (4%)

```
Д 9430 «Прочие операционные расходы» / К 6410 «Налоги к уплате»
Сумма = (Выручка 9010 + 9020 + 9030) × 4%
```

### 4.12 Налог на прибыль (15%)

```
Д 9810 «Налог на прибыль» / К 6410 «Налоги к уплате»
Сумма = Налогооблагаемая прибыль × 15%
```

## 7. Режимы налогообложения

### Налог с оборота (TURNOVER_TAX)

Применяется к субъектам малого предпринимательства.

```
База: Валовая выручка (9010 + 9020 + 9030)
Ставка: 4%
Начисление: Д 9430 / К 6410
Уплата: ежеквартально, до 20-го числа следующего месяца
```

### НДС (VAT)

Применяется к крупным предприятиям и добровольным плательщикам НДС.

```
База: Оборот по реализации товаров/услуг
Ставка: 12%
Начисление (при реализации): из суммы поступления выделяется НДС
  → Д 5110 / К 9030 (без НДС) + К 6410 (НДС)
Принятие к зачёту: НДС по входящим документам → Д 4410 / К 6410
Уплата: ежемесячно, до 20-го числа следующего месяца
```

## 8. Закрытие учётного года

При годовом закрытии (`POST /api/closing/year-end`):

1. Все доходные и расходные счета (TRANSIT: 90xx–99xx) закрываются в 9910 «Итоговый результат»
2. Если сальдо 9910 — прибыль: переносится в 8330 «Нераспределённая прибыль»
3. Если убыток: переносится в 8410 «Непокрытый убыток»
4. Создаётся новый период следующего года

## 9. Формулы финансовых показателей

### Выручка
```
Revenue = Кт(9010) + Кт(9020) + Кт(9030)
```

### COGS (Себестоимость)
```
COGS = Дт(9110) + Дт(9120) + Дт(9130)
```

### Валовая прибыль
```
Gross Profit = Revenue − COGS
```

### EBIT (Операционная прибыль)
```
EBIT = Gross Profit − Дт(9410) − Дт(9420) − Дт(9430)
```

### Чистая прибыль
```
Net Profit = EBIT + Кт(93xx) − Дт(9620) − Дт(9810)
```

### Остаток денежных средств
```
Cash UZS = Остаток по счёту 5110
Cash USD = Остаток по счёту 5210 × Курс ЦБ
```
