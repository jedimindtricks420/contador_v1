## 1. Налоговые ставки (TAX_RATES)

| Налог | Константа | Ставка | Счёт начисления |
|-------|-----------|--------|----------------|
| НДС | `VAT` | 12% | Кт 6410 |
| НДФЛ | `NDFL` | 12% | Кт 6410 |
| Социальный налог (работодатель) | `SOCIAL_TAX` | 12% | Кт 6520 |
| ИНПС (вычитается из НДФЛ работника) | `INPS` | 0.1% | Кт 6530 |
| Налог с оборота | `TURNOVER_TAX` | 1–4% (настраивается) | Кт 6410 (через 9810) |
| Налог на прибыль | `PROFIT_TAX` | 15% | Кт 6410 (через 9810) |

**Важно:** Ставка налога с оборота (`turnoverTaxRate`) хранится в `Organization` и настраивается в разделе Settings. По умолчанию 4%. Используется динамически при закрытии периода.

| Счёт 6410 | НДС к уплате | Налог с оборота к уплате |

## 5. Механика закрытия счетов

### Ежемесячное закрытие (PERIOD_CLOSING)

```
Шаг 1. Закрытие доходных счетов:
  Дт 9010/9020/9030  →  Кт 9910  (выручка)
  Дт 9310–9390       →  Кт 9910  (прочие доходы осн. деят.)
  Дт 9510–9590       →  Кт 9910  (доходы фин. деят.)
  Дт 9710            →  Кт 9910  (чрезв. доходы)

Шаг 2. Закрытие расходных и контр-доходных счетов:
  Дт 9910  →  Кт 9040/9050      (возвраты, скидки)
  Дт 9910  →  Кт 9110–9130      (себестоимость)
  Дт 9910  →  Кт 9410–9440      (расходы периода)
  Дт 9910  →  Кт 9610–9690      (расходы фин. деят.)
  Дт 9910  →  Кт 9720           (чрезв. убытки)
  Дт 9910  →  Кт 9810/9820      (налоги от прибыли)

Результат: Сальдо 9910 = чистая прибыль/убыток за месяц.
Все прочие 9xxx = 0.
```

### Годовое закрытие (YEAR_END_CLOSE)

```
Если прибыль (Кт-сальдо 9910):
  Дт 9910  →  Кт 8710   (перенос прибыли в нераспределённую)

Если убыток (Дт-сальдо 9910):
  Дт 8710  →  Кт 9910   (покрытие убытка)

Результат: 9910 = 0, Кт-сальдо 8710 = накопленная нераспределённая прибыль.
```

## 6. Признание дохода (принцип начисления, НСБУ №1)

```
Доход признаётся в момент ПЕРЕХОДА ПРАВА СОБСТВЕННОСТИ
(подписание ЭСФ / акта / отгрузки), а НЕ в момент получения денег.

Деньги получены до отгрузки → Дт 5110 → Кт 6310 (аванс, строка 670 баланса)
ЭСФ подписан → Дт 4010 → Кт 9010 (выручка) + зачёт аванса 6310 → 4010
Деньги получены после отгрузки → Дебиторка 4010 (строка 220 баланса)
```

## 7. Учёт НДС (только VAT-режим)

### Три события — три проводки

| Событие | Момент | Проводка |
|---------|--------|---------|
| T0. Деньги от покупателя | Поступление аванса | Дт 5110 → Кт 6310 |
| T1. ЭСФ подписан | Признание выручки | Дт 4010 → Кт 9010 (без НДС) + Дт 4010 → Кт 6410 (НДС) + Дт 6310 → Кт 4010 (зачёт аванса) |
| T2. Уплата налога | Перечисление | Дт 6410 → Кт 5110 |

### Входящий НДС (НДС к зачёту)

```
Получение ЭСФ от поставщика:
  Дт 1010/4010 (товар без НДС)
  Дт 4410 (НДС к зачёту)
    → Кт 6010 (задолженность поставщику)

НДС к уплате нетто = Кт 6410 − Дт 4410
```

Счёт 4410 → строка 270 Баланса (авансы по налогам в бюджет).

## 8. Зарплатные налоги (оба режима)

```
Начислена зарплата:
  Дт 9420  →  Кт 6710   (административные расходы)

НДФЛ 12% (из зарплаты работника):
  Дт 6710  →  Кт 6410

ИНПС 0.1% (вычитается из НДФЛ):
  Дт 6710  →  Кт 6530

Социальный налог 12% (расход работодателя):
  Дт 9420  →  Кт 6520

Выплата на руки:
  Дт 6710  →  Кт 5110   (начислено − НДФЛ − ИНПС)

Перечисление НДФЛ в бюджет:
  Дт 6410  →  Кт 5110

Перечисление соцналога и ИНПС:
  Дт 6520  →  Кт 5110
  Дт 6530  →  Кт 5110
```

## 9. Взаимоувязка Формы №1 и Формы №2 (§8)

```
Контрольное равенство:

Нераспред. прибыль на конец периода (стр.450, 8710) =
  Нераспред. прибыль на начало периода
  + Чистая прибыль (стр.270 Формы №2)
  − Распределённые дивиденды (Дт 8710)
```

В системе Contador это достигается после выполнения `YEAR_END_CLOSE`. Строка 450 баланса в течение года включает `transitNet` (незакрытый финрезультат 9910), что даёт промежуточное актуальное значение нераспределённой прибыли.
