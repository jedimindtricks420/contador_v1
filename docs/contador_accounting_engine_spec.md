НСБУ №21 (рег. МЮ №3593 от 27.12.2024), Положение о сроках и формах финотчётности

## 1. Два режима налогообложения — два разных движка

| Параметр | Плательщик НДС + налога на прибыль | Плательщик налога с оборота |
|---|---|---|
| Ставка НДС | 12% | Нет НДС |
| Налог на прибыль | 15% от налогооблагаемой прибыли | Нет |
| Налог с оборота | Нет | 1–4% от выручки (зависит от вида деятельности) |
| Социальный налог | 12% (работодатель) | 12% (работодатель) |
| НДФЛ | 12% | 12% |
| ИНПС | 0.1% (вычитается из НДФЛ работника) | 0.1% |
| Форма №1 | Да, обязательно | Да (микро/малые — обязательно с 2026 г.) |
| Форма №2 | Да, обязательно | Да (микро/малые — обязательно с 2026 г.) |
| Срок сдачи | Не позднее 1 марта | Не позднее 1 марта (с 2026 г.) |

> **Важно:** Плательщики налога с оборота в **фиксированной** сумме освобождены от сдачи
> финотчётности по 31.12.2025 включительно (№ПП-419 от 10.11.2022). С 01.01.2026 обязанность
> возобновляется. В Contador переключатель режима налогообложения активируется в настройках
> организации.

## 3. ФОРМА №2 «ОТЧЁТ О ФИНАНСОВЫХ РЕЗУЛЬТАТАХ»

### 3.1 Каскад формул — от выручки до чистой прибыли

```
стр. 010  Чистая выручка от реализации
стр. 020  Себестоимость реализованной продукции/товаров/услуг
─────────────────────────────────────────────────────────────
стр. 030  ВАЛОВАЯ ПРИБЫЛЬ = 010 − 020

стр. 040  Расходы периода = 050+060+070+080
  050      Расходы по реализации
  060      Административные расходы
  070      Прочие операционные расходы
  080      Расходы периода, вычитаемые из н/о базы в будущем
стр. 090  Прочие доходы от основной деятельности
─────────────────────────────────────────────────────────────
стр. 100  ПРИБЫЛЬ ОТ ОСНОВНОЙ ДЕЯТЕЛЬНОСТИ = 030 − 040 + 090

стр. 110  Доходы от финансовой деятельности = 120+130+140+150+160
  120      Доходы в виде дивидендов
  130      Доходы в виде процентов
  140      Доходы от финансовой аренды (лизинга)
  150      Доходы от валютных курсовых разниц
  160      Прочие доходы от финансовой деятельности
стр. 170  Расходы по финансовой деятельности = 180+190+200+210
  180      Расходы в виде процентов
  190      Расходы по финансовой аренде
  200      Убытки от валютных курсовых разниц
  210      Прочие расходы по финансовой деятельности
─────────────────────────────────────────────────────────────
стр. 220  ПРИБЫЛЬ ОТ ОБЩЕХОЗЯЙСТВЕННОЙ ДЕЯТЕЛЬНОСТИ = 100 + 110 − 170

стр. 230  Чрезвычайные прибыли и убытки (±)
─────────────────────────────────────────────────────────────
стр. 240  ПРИБЫЛЬ ДО УПЛАТЫ НАЛОГА = 220 ± 230

стр. 250  Налог на прибыль (15%) / налог с оборота

─────────────────────────────────────────────────────────────
стр. 270  ЧИСТАЯ ПРИБЫЛЬ = 240 − 250 − 260
```

## 4. УЧЁТ НДС (только для плательщиков НДС)

### 4.1 Три события — три момента в времени

| Событие | Момент | Проводка | Строка баланса |
|---------|--------|----------|----------------|
| Деньги пришли от покупателя | T0 | Дт 5110 → Кт 6310 (аванс полученный) | стр. 670 пассив |
| ЭСФ подписан, реализация признана | T1 | Дт 4010 → Кт 9010 (выручка без НДС) + Дт 4010 / Кт 6410 (НДС к уплате) + Дт 6310 → Кт 4010 (зачёт аванса) | стр. 220 актив / стр. 680 пассив |
| Налог уплачен в бюджет | T2 | Дт 6410 → Кт 5110 | стр. 680 → 0 |

### 4.2 Входящий НДС (НДС к зачёту)

```
При получении ЭСФ от поставщика:
  Дт 1010/4010 (товар/расход без НДС)
  Дт 4410 (НДС к зачёту)
    →  Кт 6010 (задолженность поставщику)

НДС к уплате в бюджет (нетто):
  НДС к уплате = (сумма НДС по выставленным ЭСФ, счёт 6410)
               − (сумма НДС по полученным ЭСФ, счёт 4410)

Проводка зачёта:
  Дт 6410  →  Кт 4410   (на меньшую сумму)
  Остаток по Дт 6410 — к уплате в бюджет → стр. 680 баланса
  Остаток по Дт 4410 — переносится → стр. 270 баланса
```

### 4.3 Выручка в Форме №2 — всегда БЕЗ НДС

```
стр. 010 = выручка без НДС  (кредит счёта 9010/9020/9030)
НДС не входит в доходы и не входит в расходы
```

## 5. УЧЁТ НАЛОГА С ОБОРОТА

### 5.1 База налога

```
Налог с оборота = Валовая выручка × Ставка (1–4%)

Валовая выручка = все поступления от реализации,
                  включая стоимость отгруженных товаров/услуг
                  БЕЗ разбивки на НДС (его нет)
```

### 5.2 Проводки

```
Начислен налог с оборота:
  Дт 9810  →  Кт 6410   (задолженность по налогу в бюджет)

Уплата:
  Дт 6410  →  Кт 5110

В Форме №2:
  стр. 010  = полная выручка (без вычета налога с оборота)
  стр. 250  = налог с оборота  ← берётся из 9810
  стр. 270  = стр. 240 − стр. 250 − стр. 260
```

### 5.3 Отличие от НДС-режима

| | НДС-режим | Налог с оборота |
|---|---|---|
| Выручка стр. 010 | Без НДС | Полная (НДС нет) |
| Счёт 4410 | Используется (зачёт входящего НДС) | Не используется |
| Счёт 6410 | НДС к уплате | Налог с оборота к уплате |
| Счёт 9810 | Налог на прибыль | Налог с оборота |
| Аванс от покупателя | 6310 до ЭСФ | 6310 до отгрузки/акта |

## 6. ЗАРПЛАТНЫЕ НАЛОГИ (оба режима)

### 6.1 Начисление зарплаты

```
Начислена зарплата:
  Дт 2010/9420/9430  →  Кт 6710   (начисленная з/п)

НДФЛ 12% (удерживается из зарплаты работника):
  Дт 6710  →  Кт 6410   (НДФЛ к удержанию)

ИНПС 0.1% (вычитается из рассчитанного НДФЛ, уменьшает его):
  НДФЛ к перечислению = НДФЛ рассчитанный − ИНПС
  Дт 6710  →  Кт 6520   (ИНПС)

Социальный налог 12% (расход работодателя):
  Дт 2010/9420/9430  →  Кт 6520   (соцналог)

Выплата зарплаты на руки:
  Дт 6710  →  Кт 5110   (сумма = начислено − НДФЛ − ИНПС)

Перечисление НДФЛ в бюджет:
  Дт 6410  →  Кт 5110

Перечисление соцналога и ИНПС:
  Дт 6520  →  Кт 5110
```

## 7. ПРИЗНАНИЕ ДОХОДА — принцип начисления (НСБУ №1, 2025)

```
Доход признаётся в момент ПЕРЕХОДА ПРАВА СОБСТВЕННОСТИ
(подписание ЭСФ / акта выполненных работ / отгрузки),
а НЕ в момент получения денег.

Деньги получены до отгрузки → счёт 6310 «Авансы полученные»
  (строка 670 баланса — ОБЯЗАТЕЛЬСТВО, не доход)

ЭСФ подписан → доход признан → счёт 9010 → строка 010 Формы №2
  Одновременно: аванс 6310 закрывается → дебиторка 4010 закрывается

Деньги получены после отгрузки → дебиторская задолженность 4010
  (строка 220 баланса — АКТИВ)
```

## 8. ВЗАИМОУВЯЗКА ФОРМЫ №1 И ФОРМЫ №2

```
Контрольная точка (обязательная проверка в Contador):

Нераспределённая прибыль (стр. 450, счёт 8710) на конец периода =
  Нераспределённая прибыль на начало периода
  + Чистая прибыль (стр. 270 Формы №2)
  − Распределённые дивиденды (дебет счёта 8710)

Если равенство не выполняется → ошибка в проводках → блокировать отправку отчёта.
```

## 11. ОСОБЫЕ СЛУЧАИ ДЛЯ МАЛЫХ ПРЕДПРИЯТИЙ И МИКРОФИРМ

| Критерий | Микрофирма | Малое предприятие |
|----------|------------|-------------------|
| Численность (промышл.) | до 10 чел. | до 40 чел. |
| Выручка | до 1 млрд сум/год | до 10 млрд сум/год |
| Состав финотчётности | Баланс + Форма №2 | Баланс + Форма №2 |
| Доп. формы (капитал, ОДДС) | Не требуются | Не требуются |
| Срок сдачи | 1 марта | 1 марта |

В Contador: при признании организации микрофирмой/малым предприятием
система автоматически скрывает Форму №4 (ОДДС) и Форму №5 (капитал)
из обязательного пакета, оставляя только Баланс + Форма №2.
