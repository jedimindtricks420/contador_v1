# Типы документов (категории платежей) — Движок V2

Все категории определены в `v2/src/lib/ensureBaseData.ts` и сеются в таблицу `DocumentType` при каждом старте.

Итого: **37 типов** (24 банковских + 8 начислений + 5 прочих/внутренних).

---

## Банковские операции — Поступления (CREDIT)

| Код | Название | Счёт Дт | Счёт Кт | Контрагент | OpenItem |
|-----|----------|---------|---------|-----------|---------|
| `REVENUE_VAT` | Поступление от покупателя (с НДС) | 5110 | 9030 + 6410 | Обязателен | — |
| `REVENUE_NO_VAT` | Поступление от покупателя (без НДС) | 5110 | 9030 | Обязателен | — |
| `ADVANCE_RECEIVED` | Аванс полученный | 5110 | 6310 | Обязателен | Открывает по 6310 |
| `FOUNDER_LOAN` | Займ от учредителя | 5110 | 6820 | Обязателен | Открывает по 6820 |
| `MARKETPLACE_INCOME` | Поступление от маркетплейса (нетто) | 5110 + 9430 | 9030 | Обязателен | — |
| `SUPPLIER_REFUND` | Возврат от поставщика | 5110 | 4310 | Обязателен | — |
| `BANK_LOAN_RECEIVED` | Получение банковского кредита | 5110 | 6810 | Обязателен | Открывает по 6810 |
| `EMPLOYEE_LOAN_REPAYMENT` | Возврат займа сотрудником | 5110 | 4720 | — | — |

> `REVENUE_VAT`: НДС выделяется автоматически. Сумма НДС = `amount − amount / 1.12`. Выручка без НДС = `amount / 1.12`.
> `MARKETPLACE_INCOME`: Дт 5110 (сумма поступления `netAmount`), Дт 9430 (комиссия `commissionAmount`), Кт 9030 (полная выручка `amount`).

## Начисления (неденежные операции)

Создаются автоматически в процессе закрытия периода или через ручной ввод (не привязаны к банковским транзакциям).

| Код | Название | Проводки | Режим ввода |
|-----|----------|---------|------------|
| `SALARY_ACCRUAL` | Начисление зарплаты и налогов ФОТ | Д9420/К6710 (gross), Д6710/К6410 (НДФЛ 12%), Д9420/К6520 (соцналог 12%) | Автоматический / Закрытие |
| `DEPRECIATION_ACCRUAL` | Начисление амортизации ОС | Д9430/К0200 | Автоматический / Закрытие |
| `RENT_ACCRUAL` | Начисление аренды (неденежное) | Д9420/К6010 | Ручной ввод |
| `FX_DIFFERENCE` | Курсовая разница валютных счетов | Д5210/К9540 (доход) или Д9620/К5210 (расход) | Автоматический / Закрытие |
| `PROFIT_TAX_ACCRUAL` | Начисление налога на прибыль | Д9810/К6410 | Автоматический / Закрытие |
| `GOODS_RECEIVED` | Поступление товаров (начисление) | Д9120 / К6010 | Ручной ввод (manualOnly) |
| `SERVICE_RECEIVED` | Получение услуги (начисление) | Д9130 / К6010 | Ручной ввод (manualOnly) |

## OpenItem — открытые позиции

Типы с `opensItem: true` создают запись в таблице `OpenItem`, которая отслеживается до закрытия встречной операцией:

| Код | Счёт OpenItem | Когда закрывается |
|-----|--------------|------------------|
| `ADVANCE_RECEIVED` | 6310 (Авансы полученные) | При выставлении ЭСФ / отгрузке |
| `ADVANCE_PAID` | 4310 (Авансы выданные) | При получении товара / услуги (`GOODS_RECEIVED` / `SERVICE_RECEIVED`) |
| `FOUNDER_LOAN` | 6820 (Займы от учредителей) | При возврате займа |
| `ACCOUNTABLE` | 4220 (Авансы сотрудникам) | При сдаче авансового отчёта |
| `DEPOSIT` | 5830 (Депозиты обеспечения) | При возврате депозита |
| `BANK_LOAN_RECEIVED` | 6810 (Краткосрочные кредиты) | При погашении кредита (`BANK_LOAN_REPAYMENT`) |
| `EMPLOYEE_LOAN` | 4720 (Задолженность по займам) | При возврате займа сотрудником (`EMPLOYEE_LOAN_REPAYMENT`) |
