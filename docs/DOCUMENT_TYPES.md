# Типы документов (категории платежей) — Движок V2

> **Этот файл больше не дублирует каталог типов документов.** Ранее здесь поддерживалась
> отдельная копия таблицы проводок, которая расходилась с реальным кодом (например, всё ещё
> описывала `SUPPLIER_PAYMENT_GOODS/SERVICES/OTHER` по кассовому методу — 9120/9130/9430 —
> хотя движок уже год как перешёл на метод начисления через 6010, см.
> `docs/ACCRUAL_METHOD_MIGRATION.md`; путала `DEPOSIT`/`5830` вместо реального `4890`).
> Поддерживать одно и то же в двух местах вручную — источник рассинхронизации, поэтому здесь
> остаётся только ссылка.

**Источник истины:** [`v2/docs/modules/module_DOCUMENT_TYPES.md`](../v2/docs/modules/module_DOCUMENT_TYPES.md)
— полный, актуальный список всех типов документов, их проводок, режимов (`BANK_AUTO` /
`MANUAL_ONLY`), OpenItem-буферов и известных ограничений движка. Генерируется на основе
`v2/src/lib/ensureBaseData.ts` (единственное место, где определяются шаблоны проводок) и
обновляется вместе с ним.

Для более широкого контекста (архитектура движка, налоги, отчётность) см. также:
- [`docs/05_BUSINESS_LOGIC.md`](05_BUSINESS_LOGIC.md) — бизнес-логика, начисления, закрытие периода
- [`docs/09_ACCOUNTING_REFERENCE.md`](09_ACCOUNTING_REFERENCE.md) — план счетов, ставки налогов
- [`v2/docs/modules/`](../v2/docs/modules/) — модульная документация движка (A–H)
