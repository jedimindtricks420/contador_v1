# Типы документов (категории платежей) — Движок V2

Все типы документов определены в `v2/src/lib/ensureBaseData.ts` и создаются автоматически в таблице `DocumentType` при каждом старте приложения.

**Итого: 38 типов** (24 банковских + 9 начислений/системных + 5 прочих)  
**Последнее обновление:** 2026-06-26

---

|-----|----------|---------|---------|-----------|---------|
| `REVENUE_VAT` | Поступление от покупателя (с НДС) | 5110 | 9030 + 6410 | Обязателен | — |
| `REVENUE_NO_VAT` | Поступление от покупателя (без НДС) | 5110 | 9030 | Обязателен | — |
| `ADVANCE_RECEIVED` | Аванс полученный | 5110 | 6310 | Обязателен | Открывает 6310 |
| `FOUNDER_LOAN` | Займ от учредителя | 5110 | 6820 | Обязателен | Открывает 6820 |
| `MARKETPLACE_INCOME` | Поступление от маркетплейса (нетто) | 5110 + 9430 | 9030 | Обязателен | — |

## Начисления (неденежные операции)

Создаются автоматически при закрытии периода или через ручной ввод.

| Код | Название | Проводки | Режим |
|-----|----------|---------|-------|
| `SALARY_ACCRUAL` | Начисление зарплаты | Дт 9420 → Кт 6710 (gross) | Авто / Закрытие |
| `SALARY_OFFSET` | Удержание НДФЛ + ИНПС | Дт 6710 → Кт 6410 (НДФЛ 12%) + Кт 6530 (ИНПС 0.1%) | Авто / Закрытие |
| `DEPRECIATION_ACCRUAL` | Начисление амортизации ОС | Дт 9430 → Кт 0200 | Авто / Закрытие |
| `FX_DIFFERENCE` | Курсовая разница | Дт 5210 → Кт 9540 (доход) / Дт 9620 → Кт 5210 (расход) | Авто / Закрытие |
| `PROFIT_TAX_ACCRUAL` | Налог на прибыль (VAT-режим, 15%) | Дт 9810 → Кт 6410 | Авто / Закрытие |
| `TURNOVER_TAX_ACCRUAL` | Налог с оборота (TURNOVER_TAX, 1–4%) | Дт 9810 → Кт 6410 | Авто / Закрытие |
| `GOODS_RECEIVED` | Поступление товаров (начисление) | Дт 9120 → Кт 6010 | Ручной ввод |
| `SERVICE_RECEIVED` | Получение услуги (начисление) | Дт 9130 → Кт 6010 | Ручной ввод |
| `RENT_ACCRUAL` | Начисление аренды | Дт 9420 → Кт 6010 | Ручной ввод |

## Важные примечания

1. **TURNOVER_TAX_ACCRUAL** — начисляется при `taxRegime = TURNOVER_TAX`. Ставка берётся из `org.turnoverTaxRate` (настраивается в разделе Settings). Формула: `totalRevenue × turnoverTaxRate`.

2. **SALARY_OFFSET** — отдельный тип от SALARY_ACCRUAL. Создаётся в паре с SALARY_ACCRUAL при закрытии месяца. Обрабатывает НДФЛ и ИНПС.

3. **REFUND** использует счёт **9040** (возврат продукции) — CONTRA_LIABILITY, уменьшает выручку. Не использует 9030 (выручка).

4. **PERIOD_CLOSING** исключается из агрегатов Формы №2 (`dt.code != 'PERIOD_CLOSING'`), чтобы не задваивать обороты.

5. Все типы документов создаются через `upsert` при каждом запуске — безопасно при повторных стартах.
